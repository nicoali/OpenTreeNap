# OpenTreeNap Android origin and compatibility notes

OpenTreeNap Android is a modern client for the OpenTreeNap/OpenTreeMap API.

The implementation is informed by the historical open-source
[OpenTreeMap/otm-android](https://github.com/OpenTreeMap/otm-android) client,
whose last upstream commit is `c9a5bdca3f0a46039ff97f9302c9c869368c8901`
(10 January 2017).

V0.1 preserves API-v4 compatibility and the historical HMAC-SHA256 signing
scheme while replacing the obsolete Android build and networking stack.
